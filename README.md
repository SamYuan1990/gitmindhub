# gitmindhub


## Dev set up
```
npm install
npm run dev
```

tips:
```
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install electron --save-dev --loglevel verbose
or
npm config set ELECTRON_MIRROR https://npmmirror.com/mirrors/electron/
npm install --loglevel verbose
```
