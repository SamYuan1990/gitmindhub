# 🌳 GitMindHub

**Git-style context visualization chatbox.**

Welcome to the official documentation of GitMindHub. 

## What is GitMindHub?

GitMindHub is a local-first, open-source chatbox that treats your AI conversation context like a Git repository. 

- **Branching**: Fork your conversations to explore different AI responses without losing the original context.
- **Version Control**: Every prompt is a commit. Time-travel through your chat history.
- **Visual DAG**: See your context grow as a beautiful Directed Acyclic Graph.
