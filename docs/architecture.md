## 核心模块解析

### 1. 双数据库协同 (Dual-Database)
- **SQLite (`better-sqlite3`)**：负责存储关系型元数据，包括消息内容、`parent_uuid` 指针、分支名称等。利用其事务特性保证 DAG 结构的一致性。
- **LanceDB (`@lancedb/lancedb`)**：负责存储高维向量数据。Lance 格式专为机器学习设计，支持极速的 ANN（近似最近邻）搜索，且无需额外的服务端进程。

### 2. 智能 DAG 布局算法
在 `DagView.jsx` 中，我们实现了一个基于**子树宽度 (Subtree Width)** 的自动布局算法。
- 传统的树状布局在处理多分支时容易导致节点严重重叠。
- 我们的算法先递归计算每个节点作为根的子树包含的叶子节点总数（即宽度），然后按宽度比例分配 X 轴坐标。
- 这保证了无论对话树多么复杂，节点之间都能保持完美的间距，无需手动拖拽。

### 3. 安全的 IPC 桥接
通过 Electron 的 `contextBridge` 和 `preload.js`，我们将 Node.js 后端的数据库操作安全地暴露给 React 渲染进程，严格遵循 `contextIsolation: true` 和 `nodeIntegration: false` 的安全最佳实践。
